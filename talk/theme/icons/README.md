# AWS Architecture Icons

Official icons from the AWS Architecture Icons package of 31 July 2026
(https://aws.amazon.com/architecture/icons/), copied unchanged: 64 px service icons at @5x, 48 px resource icons in
their dark-background variants, and the AWS Cloud and Region group icons. AWS allows their use in architecture
diagrams and presentations; see the page above and https://aws.amazon.com/terms/.

`build_deck.py` uses them for the architecture and medallion diagrams (`icon()`, `group()`).
